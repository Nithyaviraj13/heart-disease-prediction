# Heart Disease Prediction

A machine learning project that predicts whether a patient has heart disease from 13 routine clinical measurements, comparing four classifiers with cross-validation and explaining which features drive the predictions.

## Problem
Heart disease is a leading cause of death worldwide, and early detection improves outcomes. This project builds a binary classifier that flags likely heart disease from measurements such as age, resting blood pressure, cholesterol and maximum heart rate.

## Dataset
- **Source:** UCI Heart Disease dataset (Cleveland subset), https://archive.ics.uci.edu/ml/datasets/heart+Disease
- **File:** `processed.cleveland.data`
- **Size:** 303 records, of which 6 had missing values and were removed, leaving 297 records, 13 features and 1 binary target
- **Target:** original 0-4 severity scale converted to 0 = no disease, 1 = disease

The notebook contains a table describing every feature.

## Approach
1. Loaded the raw UCI file, removed rows with missing values and converted the target to binary
2. Exploratory analysis: class balance and feature correlations
3. Stratified 80/20 train/test split (`random_state=2`)
4. **Baseline:** Logistic Regression on raw features (83.3% test accuracy)
5. Compared Logistic Regression, KNN, SVM (RBF) and Random Forest using standardised features and 5-fold cross-validation, with scaling inside a pipeline to avoid data leakage
6. Tuned the best candidates with `GridSearchCV`
7. Evaluated the final model once on the held-out test set (accuracy, precision, recall, F1, ROC-AUC, confusion matrix)
8. Ranked features with permutation importance

## Results

Models were ranked by 5-fold cross-validated accuracy on the training set. The test set (60 patients) was used only for the final report.

| Model | CV Accuracy | Test Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|---|---|
| Logistic Regression | 0.831 | 0.833 | 0.800 | 0.857 | 0.828 | 0.893 |
| Random Forest | 0.818 | 0.800 | 0.767 | 0.821 | 0.793 | 0.891 |
| KNN | 0.810 | 0.867 | 0.833 | 0.893 | 0.862 | 0.867 |
| SVM (RBF) | 0.806 | 0.850 | 0.828 | 0.857 | 0.842 | 0.896 |
| **Logistic Regression (tuned)** | **0.843** | **0.833** | **0.800** | **0.857** | **0.828** | **0.903** |

**Final model:** Logistic Regression (tuned with `GridSearchCV`), chosen for the best cross-validated accuracy (84.3%). On the held-out test set it reached 83.3% accuracy, 85.7% recall and 0.903 ROC-AUC.
**Most influential features** (permutation importance): `ca` (major vessels coloured by fluoroscopy), `thal` (thalassemia test result) and `cp` (chest pain type).

Test accuracy matched the untuned baseline (83.3%); the gains from scaling and tuning show up in cross-validated accuracy (83.1% to 84.3%) and ROC-AUC (0.893 to 0.903), which are steadier measures on a dataset this small.

KNN scored higher on this particular test split, but with only 60 test patients one or two patients change the score by several points, so the model was selected on cross-validation rather than on the test set.

## Limitations and Next Steps
- Only 297 usable records, so scores vary with the split; a larger dataset is needed before trusting the numbers.
- The data comes from a single study population and may not generalise.
- Planned: gradient boosting, probability calibration, and a small Streamlit app for live predictions.

*Educational project, not a medical diagnostic tool.*
