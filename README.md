# 🫀 Heart Disease Prediction

This project uses **Machine Learning** to predict whether a patient is likely to have heart disease based on clinical data.  
It applies various ML techniques on healthcare datasets and demonstrates how data-driven models can assist in medical diagnosis.

---

## 📌 Project Overview
- Built a predictive model for **heart disease classification**.  
- Preprocessed patient data (age, cholesterol, blood pressure, etc.).  
- Trained ML models and evaluated their performance.  
- Visualized feature importance and prediction outcomes.  

---

## 🛠 Tech Stack
- **Python**
- **Jupyter Notebook**
- Libraries:  
  - `pandas`, `numpy` → Data manipulation  
  - `matplotlib`, `seaborn` → Data visualization  
  - `scikit-learn` → Machine learning models & evaluation  

---

## 📊 Dataset
- Dataset: [UCI Heart Disease Dataset](https://archive.ics.uci.edu/ml/datasets/heart+Disease)  
- Features: Age, sex, chest pain type, cholesterol, resting blood pressure, etc.  
- Target: Presence or absence of heart disease.
